# infrastructure/deployment

Deployment configuration for wherever PerfPilot is hosted for the hackathon demo (e.g. a single-host Docker Compose deployment). Not implemented yet, and deliberately minimal — no Kubernetes, no multi-region, no autoscaling. See [docs/roadmap.md](../../docs/roadmap.md#phase-3-deferred-by-design-not-oversights) for what's explicitly out of scope.
